# 📚 Sección 1: Welcome: Why Master Advanced Microservices Patterns?

## 🎯 Objetivo del curso

Este curso forma parte de una serie de cinco cursos sobre programación reactiva y microservicios con Spring WebFlux. Se
centra en la **integración entre microservicios y los patrones de diseño que permiten construir arquitecturas más
resilientes**.

En una arquitectura de microservicios, múltiples servicios trabajan de forma independiente, pero necesitan comunicarse
entre sí para ofrecer funcionalidades completas. Esta interacción plantea desafíos relacionados con la integración, la
comunicación y la tolerancia a fallos.

El objetivo del curso es **identificar estos problemas y aprender a resolverlos mediante patrones de diseño
específicos**, aplicados a la arquitectura de microservicios.

## 🧩 ¿Qué son los patrones de diseño?

Los patrones de diseño son soluciones reutilizables a problemas habituales del desarrollo de software. No son
implementaciones únicas, sino enfoques que pueden adaptarse a diferentes situaciones.

Existen patrones para distintos contextos:

- **Programación orientada a objetos:** patrones como *Factory*, que facilita la creación de objetos, y *Strategy*, que
  permite intercambiar comportamientos.
- **Arquitectura de microservicios:** patrones que ayudan a integrar servicios, coordinar sus interacciones y mejorar la
  resiliencia ante fallos.

En este curso estudiaremos patrones orientados a resolver problemas frecuentes de integración y resiliencia en sistemas
de microservicios desarrollados con tecnologías reactivas.

## 🛠️ Metodología del curso

El curso aborda diez patrones, agrupados en dos categorías. Cada patrón se estudia siguiendo una misma metodología:

1. **Identificar el problema** que se busca resolver.
2. **Comprender la solución** que propone el patrón.
3. **Implementar el patrón** mediante código.
4. **Probar y verificar** su comportamiento.

De esta manera, cada patrón se estudia tanto desde su fundamento teórico como desde su aplicación práctica.
